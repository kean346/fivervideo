# paceIT Fiverr profile video

58-second edited profile video, built with Remotion, React, TypeScript, and FFmpeg. All five founder recordings are included in the latest upload order. Quiet lead-ins/tails are shortened; spoken content is preserved. Full-resolution original portfolio screenshots, real paceIT/Flow recordings, phrase captions, restrained motion graphics, synthesized music and effects, and the required Fiverr end card are included.

## Edit and render

Use Node 24+ and Chromium. This cloud environment has `/usr/bin/chromium` and FFmpeg. Use the existing isolated checkout; do not create a worktree.

```sh
cd /workspace/fivervideo
npm ci --cache /workspace/npm-cache
npm run typecheck
npm run studio
npm run preview
npm run render
python scripts/qc.py
```

On another machine, run the commands from the extracted project folder and adjust the Chromium path in `package.json`. The archive includes normalized camera footage, all rendered-media dependencies, scripts, reviewed transcripts, captions and timing data. Original 4K MOVs remain in the cloud workspace and are omitted from the archive to reduce download size.

## Files

- `src/video.tsx`: reusable browser frame, camera treatment, manually synchronized gesture effects, portfolio sections, workflow scene, captions and end card.
- `src/timeline.json`: source trim, duration and output position for each of the five camera clips, in 30 fps frames.
- `src/captions.json`: reviewed phrase text and frame timings. `deliverables/paceIT-captions.srt` is the portable subtitle export.
- `public/take1.mp4` through `take5.mp4`: 1080p30 copies with processed original audio.
- `public/flow.png`, `northstar.png`, `paceit.png`, `saft.png`: original images from the supplied ZIP.
- `public/paceit.mp4`, `flow.mp4`: supplied screen recordings.
- `public/score.wav`, `effects.wav`: original synthesized music and restrained effects, generated by the included Python scripts.
- `review/verified1.json` through `verified5.json`: medium.en word timings, checked against small.en recognition and the recorded audio's speech boundaries.
- `scripts/finalize-edit.py`: regenerate the final timeline, phrase captions and SRT from reviewed transcripts. Re-run after deliberately editing transcript/timing data.
- `scripts/prepare.py`: reproduce normalized footage and original score from the original MOVs; requires NumPy and FFmpeg.
- `scripts/effects.py`: reproduce sound effects with NumPy.
- `scripts/transcribe.py`: initial automatic transcription helper; do not overwrite reviewed captions with unreviewed recognition output.

SA Family Travel is shown using its original screenshot and its appearance in the actual paceIT walkthrough. A separate SAFT website recording was not supplied. Automation is explicitly illustrative; dashboard/demo data are not represented as customer results. See the QC report for the scope and limitations of validation.
